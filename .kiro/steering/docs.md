# Documentation File Placement

All Markdown documentation files (`.md`) must be placed in the `docs/` folder at the project root.

## Rules

- **README.md** is the only `.md` file allowed at the project root.
- All other `.md` files (deployment guides, fix summaries, task reports, changelogs, etc.) must go in `docs/`.
- When creating new documentation, always place it in `docs/` — never at the root level.
- If you encounter a `.md` file at the root (other than README.md), move it to `docs/` before committing.
